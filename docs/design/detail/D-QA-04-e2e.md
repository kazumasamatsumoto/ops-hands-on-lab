# D-QA-04 E2E テスト

版: 1.0 / 親: [QA 方式](/design/architecture/06-qa) / 対象: 主要な導線(一覧 → 詳細 → ログイン → 注文履歴)と画面比較

::: tip 3 行まとめ(この文書で決めたこと)
- Playwright で、利用者と同じ通り道(edge 経由)を端から端までなぞる。シナリオは「買い物の導線」「他人の注文が見えない」「画面比較」の 3 本。
- 確かめるのは、利用者が頼りにする物(見出し・商品名・価格・注文の合計)が出ていること。細かい HTML の形には頼らない。
- わざと壊すスイッチを入れたら落ちること(= テストが効いていること)も確かめる。
:::

## 1. 目的と範囲 {#s1}
- **目的**: 変更のたびに「買い物の途中で行き止まりにならない」「他人の注文が見えない」「見た目が崩れていない」を機械で確かめる。
- **含む**: シナリオ、確かめる物、データ、画面比較の決まり、壊したときに落ちることの確認。
- **含まない**: 単体テスト、負荷。

## 2. 前提 {#s2}
| 前提 | 内容 |
| --- | --- |
| 道具 | Playwright(Docker イメージ `mcr.microsoft.com/playwright` で動かす) |
| 相手 | ラボの Docker ネットワークの中から `http://edge:8080`(利用者と同じ通り道) |
| データ | 見本の会員 `alice`・`bob`(パスワード `password`)。見本の商品 30 件 |
| 置き場所 | テストのコードは tools/ 配下に置く。実行の手順は [QA-1 の演習](/exercises/11-qa-e2e-regression) |

## 3. 全体像 {#s3}
| # | シナリオ | 手順 | 確かめる物 |
| --- | --- | --- | --- |
| 1 | 買い物の導線 | トップ → 商品一覧 → 商品詳細 → ログイン(alice)→ 注文履歴 → 注文の詳細 | 各画面の見出し、商品名と価格、ログイン後に注文履歴を開けること、注文の一覧が 1 件以上、注文の合計 |
| 2 | 他人の注文が見えない | bob でログイン → alice の注文の詳細の URL を直接開く | 「見つかりません」と出て、alice の注文の中身が出ない |
| 3 | 画面比較 | トップ・商品一覧・商品詳細の画面を撮る | 基準画像との違いが決めた範囲の中 |

## 4. 仕様 {#s4}
### 4.1 確かめ方の決まり {#s4-1}
| 決まり | 内容 | 理由 |
| --- | --- | --- |
| 見つけ方 | 画面の文字や役割(見出し・リンク・ボタン)で探す | HTML の細かい形(クラス名)に頼ると、見た目を少し変えただけで落ちる |
| 待ち方 | 「見えるまで待つ」を使い、固定の秒数では待たない | 速い日も遅い日も同じ結果にする |
| データ | 見本のデータだけを使い、テストの中で変えない | 何度流しても同じ結果にする |
| 描画モード | 商品詳細では `X-Render-Mode` が `ssr` であることも見る | SSR が壊れて CSR に逃げていても画面は出るので、見た目だけでは気づけない |

### 4.2 画面比較の決まり {#s4-2}
| 決まり | 内容 |
| --- | --- |
| 基準画像 | 最初に撮った画像を基準として保存し、リポジトリで管理する |
| 画面の大きさ | 固定する(撮るたびに変わらないように) |
| 隠す部分 | 毎回変わる部分(時刻・描画モードの表示など)は隠してから比べる |
| 更新 | 意図した見た目の変更なら基準画像を撮り直し、レビューで承認する |

### 4.3 壊したときに落ちること {#s4-3}
| スイッチ | 落ちるべきシナリオ | 理由 |
| --- | --- | --- |
| `tools/chaos.sh set idorBug=true` | 2(他人の注文が見える) | 認可の抜けを見つけられるか |
| `tools/chaos.sh set errorRate=1` | 1(商品一覧がエラー) | API の障害を見つけられるか |
| `SSR_WINDOW_BUG=true docker compose up -d web` | 1(500 の画面) | SSR の不具合を見つけられるか |

確かめたら必ず `tools/chaos.sh reset`(web は `docker compose up -d web`)で戻す。

## 5. 目標と確認方法 {#s5}
| 項目 | 目標 |
| --- | --- |
| 通常時 | 3 本とも通る |
| 壊したとき | 4.3 の表のとおりに落ちる |
| 所要時間 | 数分以内(変更のたびに流せる長さ) |
